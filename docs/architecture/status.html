Known issues

IssueImpactNotes
No OBD data while streaming CANhighThe once-a-minute OBD interlude fires but returns nothing, so coolant, fuel, voltage, load, temperatures are not recorded when "Record CAN signals" is on. Likely the raw request format under ATCAF0; the stream keeps no raw log, so the next step is to capture the interlude's ELM traffic.
CAN combined-filter mode unverified on the carmediumThe stream now probes a single mask covering all three ND2 frames before falling back to rotation (Hardware → OBD). Both paths pass unit tests against a scripted adapter; whether the Veepeak survives mask 0x501 on the real bus is the next drive's question — Settings shows which mode was chosen. The fallback rotation itself is 3× faster than the Oct 19 drive (250 ms dwell, three IDs, prompt-driven switching) but also unmeasured on hardware.
Steering centre unverifiedmediumLogged range −216° to +478° is asymmetric. Check against a known straight-ahead before building anything (e.g. understeer) on it. The 15:1 ratio is also assumed.
RaceBox heading never validlowheadingValid has never been set on the real device, so gps.course comes from the phone at 1 Hz.
Motion-source label before a fixlowmotionSourceSegments marks the RaceBox as the source as soon as it streams, not when it has a fix. A cold start took 135 s to fix, during which the phone actually supplied position.
No battery level on a Micro behind a regulatorhardwareThe Micro reports input voltage; a regulated 5 V supply reads a flat 5.1 V until it collapses. Only a sag warning is possible.
Oil temperature unavailablehardwarePID 0x5C isn't supported by the ND2's ECU.
